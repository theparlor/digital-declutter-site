In the world

File organization that stays disciplined.

Digital Declutter is behavioral governance for file organization — 28 explicit rules, 7 skills, and a reference library that keep a workspace coherent as it grows. So an AI agent files things consistently instead of making a mess.

The problem it solves

A one-time cleanup doesn't hold. Discipline does.

Most file organization systems are really clean-up events — they restore order and then slowly lose it again as files accumulate without rules. Digital Declutter is different: it encodes the decisions that govern where everything goes, so every new file, every new engagement, every new agent session follows the same logic. Downloads is a river, not a lake. Workspaces is the destination. That sentence is a rule, and there are 27 more like it.

Chaos isn't a storage problem. It's a missing governance problem. Rules are the fix.
How you use it

Seven skills. One coherent hierarchy.

1

Diagnose & set up

Run diagnose-declutter to check prerequisites, then setup-declutter to onboard your Workspaces structure with the four-domain hierarchy in place.

2

Organize the transient zones

Three skills process the noise zones: organize-downloads, organize-desktop, and organize-documents each route files to their rightful destination using the 28-rule contract.

3

Scaffold new work

setup-workspaces and setup-engagement wire up new domains and engagement directories to the AGENTS.md placement schema — consistent structure from day one.

What makes it different

The governance chain: every decision has an authority.

The rule the whole product is built around

Behavior governs; destination resolves.

Most file organization tools conflate two distinct questions: how should I behave when handling this file? and where exactly does this file go? Digital Declutter separates them cleanly. The 28 rules govern behavior — safety, naming, engagement patterns, maintenance cadence. The AGENTS.md placement resolver governs destination. When those two authorities agree, files land correctly. When they conflict, AGENTS.md wins on placement — by rule. The governance chain is always walked in full before any organizing action:

Rules contract

28 behavioral rules across 4 categories — Safety, Behavioral, Decision, Maintenance. A fresh agent reads this before touching anything.

Placement resolver

AGENTS.md is the single authoritative source for where things land — six hard gates, engagement schema, drop-zone protocol.
